让 KUN 和妈妈，
在你的手机里用 AI 回复。

按你截图里的 Windows 电脑来。你已经安装 Ollama 了；下面从选模型开始。每一步做完再往下，不用配置服务器代码，也不用购买云模型密钥。

STEP 01 · 你已经装好 Ollama

先让 Ollama 自己说出一句话

你截图打开的是 Apps。这个页面里的 Claude Code、Codex 等入口，和拾光连接无关，不用点。

AppsChat ← 点这里Settings
到聊天页面里
选择本地模型 → 发一句“你好”
  1. 点 Ollama 左侧的 Chat。
  2. 找到显示模型名称的按钮，点开模型列表。不同版本的位置可能在聊天页顶部或输入框附近。
  3. 选择一个已经下载的本地聊天模型。不清楚选什么时，可先试 qwen2.5:3b；名称带 cloud 的不是这里说的纯本地方案。
  4. 如果提示下载，等它完成。然后发一句“你好”，等模型真正回复。
列表里找不到模型？用这个备用办法

同时按键盘 Windows 键 + R，输入 cmd，按回车。在出现的黑窗口里粘贴下面这一行，再按回车：

ollama run qwen2.5:3b

第一次会下载模型，可能较慢。出现可以输入消息的提示后，输入“你好”并按回车。模型下载本身不等于已经能聊天，要看到回复才算这一步完成。

你应该看到：Ollama 已经对“你好”给出一段回复。
STEP 02 · 只在电脑装一次

确认电脑能运行连接助手

连接助手需要 Python 3。这不是 Anaconda，手机不用装。

  1. 按 Windows 键 + R，输入 cmd，回车。
  2. 输入下面这一行并回车：
py --version

如果显示 Python 3.x.x，直接跳到第 3 步。如果提示找不到命令：

  1. 打开 Python 官方 Windows 下载页面。
  2. 下载稳定版的 Windows installer (64-bit)。安装界面如果出现 Add python.exe to PATH，请勾选，然后安装。
  3. 安装结束后关闭旧的黑窗口，重新打开，再输入 py --version 检查。
你应该看到：Python 3 开头的版本号。
STEP 03 · 不要在压缩包里面运行

下载、全部解压，再双击启动

  1. 点上面的 下载新版连接助手。
  2. 在“下载”文件夹里找到 local-ollama.zip，右键 → 全部解压缩。
  3. 打开解压后的 拾光本机版 文件夹。
  4. 双击 启动本地版.bat。如果 Windows 隐藏扩展名，它可能只显示“启动本地版”，文件类型是 Windows 批处理文件。

有一个黑窗口和一个“拾光 · Ollama 连接助手”窗口是正常的。两个都先不要关。更新旧版时，不要直接删掉旧文件夹里的 data，先在设计端导出完整备份。

你应该看到：有模型下拉框，以及「1 刷新模型」「2 测试 AI」「3 启动手机服务」的连接助手。
STEP 04 · 真正连接，而不是只打开开关

依次点这三个按钮

  1. 保持 Ollama 打开，点 1 刷新模型。在下拉框里选择刚才在 Ollama Chat 中能回复的那个模型。
  2. 点 2 测试 AI。第一次加载可能要等 1—3 分钟。看到 AI 已真实回复 后再继续。
  3. 在密码框里填一个你自己记得住的作者密码，至少 6 位。这是以后在作者端登录用的，不要发给玩家。手机故事锁屏密码仍是 420802。
  4. 点 3 启动手机服务，电脑会打开一个浏览器页面。连接助手会显示电脑入口和手机入口。

如果 Windows 弹出防火墙窗口，允许 Python 在你家里的 专用网络 通信。不要关闭整个防火墙，也不要把 Ollama 的 11434 端口开到公网。

你应该看到：模型测试有真实回复；连接助手显示“手机服务已启动”和可复制的手机网址。
STEP 05 · 把你写的 KUN 放进来

导入内容、作者登录、保存、发布

之前 GitHub 网站和现在电脑上的网址，是两个不同的地方。你以前的内容不会自动搬过来。

  1. 使用你之前编辑内容的那个浏览器，打开以前的 GitHub 设计端，在 手机与备份 → 下载完整备份 保存 JSON 文件。
  2. 回到连接助手打开的电脑设计端，在 手机与备份 → 导入完整备份 选择这个 JSON。
  3. 如果还没有内容，可以在 聊天 页面应用 KUN 或妈妈模板。确认角色的 开启 AI 对话 已勾选。
  4. 点页面上方 作者登录 / 云端，输入第 4 步自己设置的作者密码。这里叫“云端”但本机版实际保存在你的电脑。
  5. 登录后点 云端保存，再点 发布作品，确认发布。
  6. 在连接助手里点 电脑先试着玩，输入 420802，进 微信 → 聊天 → KUN，输入“我刚忙完”。等他实际回复。
只导入备份、只打开“AI 对话”开关，都不够。角色需要开启 AI，作者内容需要保存并发布，连接助手需要保持运行。
你应该看到：电脑玩家端的 KUN 或妈妈能回复你新输入的话。
STEP 06 · 手机是屏幕，电脑跑模型

把连接助手里的“手机网址”发到手机

  1. 手机打开 Wi-Fi，连接和电脑同一个路由器的网络。电脑用网线、手机用同路由器 Wi-Fi 也可以。先别用访客 Wi-Fi。
  2. 在连接助手的“手机入口”处，网络下拉框优先选 Wi-Fi 或正在用的以太网。不要选 WSL、虚拟网卡、VPN 的地址。
  3. 点 复制手机网址，通过你平常用的微信、QQ 等发给自己。
  4. 在手机复制这条网址，粘贴到 Safari 或 Chrome 的地址栏，打开。尽量不要用聊天软件的内置浏览器。
  5. 输入 420802，进入微信，找到 KUN 或妈妈发消息。
手机要用连接助手显示的完整网址。不要用 GitHub 演示网址，不要把电脑网址里的 127.0.0.1 复制到手机，也不要在手机打开 11434。手机网址已经带有 /play.html。

手机没有安装模型也能聊，因为每一句话会交给开着的电脑处理。电脑关机、睡眠，或手机离开这个网络，本机 AI 就不能用了。

你应该看到：手机上的微信能发送新消息，并收到角色回复。
STEP 07 · 以后点图标打开

放到手机桌面

iPhone：Safari 打开刚才成功的网址 → 分享按钮 → 添加到主屏幕。

Android：Chrome 打开刚才成功的网址 → 右上角菜单 → 添加到主屏幕。

不同浏览器支持不同。本地 HTTP 地址有时只能添加快捷方式，不保证独立窗口。这是网页入口，不是 APK 或 App Store 原生 App；加图标后，电脑和连接助手仍然需要开着。

IF SOMETHING DOESN'T WORK

卡住了，按症状找

点启动文件后，一闪就没了 / 显示找不到 Python

先做第 2 步，确认新打开的命令窗口里 py --version 能显示 Python 3。确认压缩包已经“全部解压”，不要直接双击压缩包里面的文件。

连接助手没有找到模型

保持 Ollama 打开，去它的 Chat 里选模型，先让它回复一句，再回连接助手刷新。连接助手只列本地模型，带 cloud 的云模型不列在免费本机列表里。

Ollama 能聊，但连接助手测试 AI 很久没回复

第一次可能在加载模型，等 1—3 分钟。关闭其他很占内存的软件，先用 qwen2.5:3b 这类较小的本地聊天模型试。不要一开始选几十 B 的大模型。确认连接助手选的名称与 Ollama Chat 一致。

电脑网页能打开，手机网页打不开
  1. 先看连接助手窗口是否还开着，手机和电脑是否同一个路由器。
  2. 确认手机用的是“手机入口”，不是 127.0.0.1。
  3. Windows 设置 → 网络和 Internet → 当前 Wi-Fi / 以太网 → 属性，找到 IPv4 地址。它应与连接助手选的地址一致。不一致时在下拉框换一项。
  4. 检查 Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙 → 更改设置，给实际运行的 Python 允许 专用 网络。不要把整个防火墙关闭。
  5. 换掉访客 Wi-Fi，暂时退出影响本地连接的 VPN 后重试。路由器的设备隔离也可能阻止手机访问电脑。
手机能打开，但显示“作者尚未发布故事”

回第 5 步：在电脑本机设计端导入内容、作者登录、保存，然后发布。GitHub 网页上的本机草稿不会自动出现在这个服务器。

手机能看聊天，但 AI 没有回复

先看电脑连接助手的“测试 AI”是否真的成功。然后检查：联系人是否开启 AI、你是否保存并重新发布、手机打开的是否是本机玩家网址。不要在公开演示页测试真实 AI。

以前能用，今天又打不开

重新打开 Ollama 和连接助手，再启动服务。电脑重启后可能换了局域网地址，要重新复制“手机入口”。固定目录里的 data 保存作者内容，不要删除；玩家记录保存在各自浏览器。

这到底收不收费？离开家还能用吗？

下载并在自己电脑运行的本地模型通常没有云 API 按条计费，但使用电脑算力、电力和下载流量。Ollama 云模型可能有另外的服务规则。本教程不要求购买云服务器。离开家或关闭电脑后，本机方案不能继续提供 AI；公开互联网分享需要另作部署和权限配置。

图形启动器需要 Python 自带的 Tkinter；接口和连接逻辑有自动测试，不能替你确认真实电脑的模型速度、网络或防火墙。无需把模型密钥、作者密码发在聊天中。
