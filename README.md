# 拾光 · 手机故事

作者设计端和玩家手机端已拆分。无需 Anaconda。先在浏览器设计内容，再发布玩家版本。

## 现在从哪里开始

打开入口：https://zhusichen520.github.io/zhusichen520/ （需仓库启用 GitHub Pages）。

1. 选择「作者设计端」。先修改手机主人、壁纸和一个联系人。
2. 在「聊天」填写角色人设、风格、剧情边界，再连续添加开场消息。可点击「KUN · 人设与双人聊天模板」预览和应用角色。应用前自动导出备份，只修改所选联系人，可选择仅换人设、保留原聊天。
3. 添加备忘录、照片或朋友圈，为聊天消息配置查看内容后的触发条件。
4. 用「游玩模式」测试，下载「备份」保留完整素材。
5. 静态模式可发布并下载独立玩家 HTML，玩家不能从它进入编辑草稿。

旧版本本机草稿会保留，不会因改版清空。内容不会自动从一台设备同步到另一台。

## 在线服务器部署

GitHub Pages 只能提供设计器与离线导出，不支持作者认证、数据库或 AI。在线版使用同一仓库的 server.py，Python 标准库，无第三方运行依赖。

[使用 Render 部署](https://render.com/deploy?repo=https://github.com/zhusichen520/zhusichen520)

render.yaml 使用付费 starter 服务和持久化磁盘，不是免费托管；部署前确认服务商显示的价格。部署时设置：

- AUTHOR_PASSWORD：自行设置的强作者密码，只填服务商安全设置，不要提交仓库。
- MODEL_API_KEY：可选，模型提供商 API 密钥；云端 API 需要密钥；本机 Ollama 不需要 API 密钥，使用 MODEL_PROVIDER=ollama 与已安装的模型。
- MODEL_NAME：默认 gpt-4.1-mini。
- MODEL_BASE_URL：默认 https://api.openai.com/v1，可用兼容 Chat Completions 的 HTTPS 服务。
- STORY_DB：持久化磁盘内数据库路径，蓝图已配置 /var/data/story.db。
- COOKIE_SECURE：在线 HTTPS 使用 1；仅本地测试可设 0。

MODEL_API_KEY 可在部署后再填，或在服务器作者端「聊天 → 连接 / 管理 AI 服务」输入。不要把它发在聊天中。作者面板配置的密钥保存在服务器 SQLite 中，不返回玩家端、不会进入草稿备份或独立玩家 HTML；部署者需保护服务器磁盘和数据库备份权限。环境变量配置的密钥优先，作者面板不能覆盖它。保存配置不等于网络连接验证成功。云模型 API 请求可能产生提供商费用；本地下载并运行的 Ollama 模型通常没有 API 按量费用，但有算力与电力成本；内置每 IP 每分钟 10 次、服务全局每分钟 60 次限制，不等于账单上限，公开运营前应在服务商设置预算。无用户账号，玩家按会话独立游玩；玩家聊天、点赞、评论、收藏和本机备忘录现保存在各自浏览器 localStorage，不提供跨设备同步；每次打开仍需密码解锁。服务采用单实例，扩容前需改共享存储和会话。

部署后访问新域名的 /studio.html，点击「作者登录 / 云端」，登录后手动「云端保存」；发布时先保存草稿，再创建独立发布快照并给出 /play.html 玩家链接。草稿修改不会自动改变发布版。作者登录有效期 12 小时，服务器重启后需重新登录。自动保存仅指本机，云端保存为手动操作。

## AI 和权限范围

玩家端只读取发布内容，不能读云端草稿、写草稿或发布。角色人设不返回公开故事 API，模型密钥仅在服务器。玩家会话互不共享，但未提供账号系统、玩家云端存档或付费会员。

AI 可在模拟聊天内扮演角色，不会操作真实微信或真实手机。人设与边界属于模型提示，不能保证模型完全遵守；重要秘密和关键解锁用固定消息与内容触发。不要向模型发送敏感信息。此版本不是具有工具执行能力的 agent。

manifest 提供添加桌面和独立窗口元数据，支持情况由浏览器决定。尚未提供离线服务缓存、推送通知或应用商店安装包，不能保证所有浏览器显示安装提示。

## 开发与验证

```sh
python3 server.py
# 本地作者登录需先在本机安全配置 AUTHOR_PASSWORD 和 COOKIE_SECURE=0
node --check app.js
python3 tests/server_test.py
# 浏览器测试依赖测试环境已有的 Playwright / Chromium；另启动静态服务器于 3000
node --test tests/studio.test.cjs
```

上传单张上限 3 MB；本机 localStorage 容量有限，及时备份。清除浏览器数据会清除本机草稿，服务器磁盘丢失也会丢失云端数据，发布不替代备份。

## 开场弹窗、图片裁剪与手机迁移

- 个性设置 → 玩家开场弹窗：启用、编辑标题/内容/进入按钮，可预览。游玩每次重新开始显示一次；对发布版生效需重新发布。
- 上传壁纸或头像后先裁剪：拖动、缩放、横向/纵向位置；取消不替换原图。壁纸输出 900×1950，头像 600×600 的 JPEG；不同手机屏幕仍可能裁掉少量边缘。GIF 经裁剪为静态图片。
- 侧栏「手机与备份」提供在手机上也可访问的导入/导出按钮。电脑素材不会自动出现在手机；静态模式需把完整 JSON 传到手机后导入。在线模式需作者保存并发布后分享独立玩家链接。
- KUN 优化文案见 content/KUN角色设定.md，网站模板位于 kun-template.json。均为虚构同人示例，不作现实人物事实陈述。AI 的关键节点仍受固定剧情约束，不能保证模型完全遵从人设。
- 新测试：node --test tests/creation.test.cjs；python3 tests/ai_test.py 使用本地假模型服务检查上下文拼装，不代表已连接真实模型。

### 本机 Ollama（无需购买云模型 API）

下载网站的 local-ollama.zip，解压后阅读「本地版使用说明.txt」。需要已有 Python 3（带 Tkinter）与 Ollama，并下载一个本地聊天模型。Windows 双击 bat，Mac 双击 command；启动器要求本次作者密码并选择已安装的模型，再打开本机设计端。GUI 启动器仅作语法与打包检查，未在真实 Windows/macOS 或用户的真实 Ollama 上验证；模型传输用本地测试服务验证。

先从 GitHub Pages 导出完整备份，在本机设计端导入，作者登录 → 保存 → 发布。电脑和手机同 Wi-Fi，手机访问启动器显示的电脑局域网地址 /play.html；防火墙可能需要允许连接。电脑要保持运行，不要把 Ollama 端口直接暴露到公网。网页与 Ollama 由本机服务器连接，不需要为浏览器开启通配 CORS。

可通过 MODEL_PROVIDER=ollama、MODEL_NAME=qwen2.5:7b、OLLAMA_BASE_URL=http://127.0.0.1:11434/v1 配置，或在无环境变量管理时通过作者 AI 面板选择 Ollama。云服务器的 localhost 不是个人电脑，不能直接使用你家里的本机模型。使用 Ollama 云端模型时，费用按其服务规则，不适用“纯本机无 API 按量费”的说明。

手机添加图标：iPhone Safari 分享 → 添加到主屏幕；Android Chrome 菜单 → 添加到主屏幕（由浏览器支持情况决定）。不是 App Store/原生 APK，不包含离线 AI；主机和网络仍需可用。

构建公开演示和本机包：python3 make_demo.py && python3 make_bundle.py。打包器使用显式文件列表，排除作者数据库、环境文件和 Git 元数据。

## Windows 详细教程与连接助手

给第一次操作的用户的完整教程在 help-ollama.html：从 Ollama 的 Chat 选择本地模型、Python 安装、全部解压到手机地址与防火墙排查。源码中的教程不包含密码或密钥。连接助手现提供已下载本地模型的下拉框、实际请求一次模型的测试按钮、服务启动按钮、电脑/手机链接和复制手机网址。云模型不会列入本地列表。GUI 未在真实 Windows/macOS 验证，模型识别、连接与地址过滤使用自动化测试验证。

新增电话、信息、音乐、日历、计算器：电话与短信都是故事模拟，不调用运营商。音乐可播放作者上传音频，公开演示只有自行生成的提示音；日历支持作者事项与玩家本机事项；计算器不使用 eval。可在个性设置隐藏桌面应用。所有新应用和资源随独立 HTML 与本机包导出。

手机内隐藏原生大滚动条，保留滚动行为，改为滚动时显示 3px×24px 的指示条，850ms 后淡出；桌面编辑面板为细滚动条。
