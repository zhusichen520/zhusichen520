# 拾光 · 手机故事工作室

手机优先的本地互动叙事创作工具，无第三方运行依赖。

## 浏览器直接访问（推荐）

本项目可直接使用 GitHub Pages，无需安装 Python、Anaconda 或其他软件。

仓库 Settings → Pages → Build and deployment：Source 选择 Deploy from a branch，Branch 选择 main，目录选择 / (root)，点击 Save。首次部署完成后访问 https://zhusichen520.github.io/zhusichen520/ 。后续推送 main 会自动更新网站。

此地址需要先在仓库中启用 Pages，源码推送本身不会自动开通网站。

## 本地开发启动（仅开发者需要）

```sh
cd /workspace/zhusichen520
python3 -m http.server 3000 --bind 0.0.0.0
```

用浏览器访问服务。不要直接双击工作室 index.html；发布导出需要通过 HTTP 读取脚本和样式。

## 使用

1. 在左侧选择内容，右侧编辑，中央实时预览。聊天表单添加消息后保持打开并保留发送方、时间和条件。
2. 草稿自动保存在当前浏览器 localStorage，刷新后恢复。图片以 data URL 保存在备份中。浏览器清理数据会删除本地内容，务必定期下载完整 JSON 备份。
3. 在剧情面板设锁屏密码；在聊天消息中选择查看某个备忘录、照片或动态后出现。游玩模式可验证剧情，重新开始可清空本次探索状态。
4. 发布会创建独立快照，并下载可离线打开的单文件 HTML。访客版不携带草稿或编辑入口。草稿更新不会改变已发布快照，再次发布才会更新。
5. 游玩模式有发布快照时使用发布版，没有时预览草稿。游玩进度不持久化；作者内容持久化。

## 实现阶段

- 基础版本：可视化编辑、联系人、双方聊天、连续输入、图片、时间、排序、本地保存、完整导入导出。
- 剧情与视觉：密码、回复选项、查看内容触发消息、独立发布快照、统一 SVG 图标、响应式手机外观。
- 云端阶段（尚未实现）：账号认证、作者权限、云端数据库和在线分享链接。当前发布采用静态游玩文件，任何拿到文件的人都可以查看故事源数据；密码仅为剧情门槛。不要用于敏感信息。

无需 API key、数据库或 AI。应用自身无远程图片/字体依赖。上传支持 PNG/JPEG/WebP/GIF，每张 3 MB 上限；浏览器本地容量通常仅数 MB，图片较多时需要优化素材。
