拾光 · 本机 Ollama 版

这份是本机服务器，不是手机原生安装包。电脑须已有 Python 3（含 Tkinter）与 Ollama，并至少下载一个聊天模型。使用本地模型通常不产生按消息计费的云模型 API 费用，但会消耗本机算力、电费。Ollama 云模型不是本地模型，可能有额外服务条款或费用。

1. 先在 GitHub Pages 设计端「手机与备份」导出完整备份 JSON，保留图片和你写过的内容。
2. 解压本机版到一个固定目录。打开 Ollama，让已下载的模型可运行。
3. Windows 双击「启动本地版.bat」；Mac 双击「启动本地版.command」。需要 Python 3；Mac 若拦截脚本，需在系统安全设置允许，或由熟悉电脑的人协助。
4. 设置这次启动的作者密码，并选择列表里已安装的本地模型。作者密码与你故事的六位密码不同。
5. 自动打开本机设计端后，先导入完整备份，再点作者登录、输入刚设的密码、云端保存（此处其实保存在本机数据库），然后发布。
6. 点击发布后的玩家链接，故事密码为 420802。AI 角色需在联系人里启用；模型需已启动。关闭启动窗口会停止服务，下次用同一目录启动，作者内容仍在 data/story.db 中。

手机浏览：
电脑和手机连接同一 Wi-Fi，使用启动窗口显示的局域网网址，在后面加 /play.html。手机使用电脑的 IP，不能写手机自己的 127.0.0.1。若打不开，检查电脑防火墙是否允许本机服务器的局域网连接；不要为此暴露 Ollama 11434 到公网。没有公网部署时，外地访客不能访问这个局域网网址。

像 App 一样打开：
iPhone：Safari 打开玩家链接 → 分享 → 添加到主屏幕。
Android：Chrome 打开玩家链接 → 菜单 → 添加到主屏幕（名称和可用选项因浏览器版本不同）。
这不是 App Store / APK 原生应用，也没有离线 AI。电脑仍要开机。无需购买云端服务器就能在家中同 Wi-Fi 使用。

数据：
作者草稿和发布快照保存在本机 data/story.db。作者密码本次启动有效，重启可重新设，不影响原内容。玩家聊天、点赞、评论和收藏保存在各自浏览器；不修改作者内容。更换设备不会自动同步，定期导出完整备份，不要只依赖这个目录。

新版连接助手：
打开后按「1 刷新模型 → 2 测试 AI → 3 启动手机服务」。模型从下拉框选择，不需要手写。
测试完成后会显示实际的模型回复。启动后有「复制手机网址」按钮，可发给自己的手机。
完整逐步教程：解压目录中的 help-ollama.html，或 https://zhusichen520.github.io/zhusichen520/help-ollama.html 。
