拾光本机版 · 浏览器连接与背景迁移

这次入口已改成浏览器设置，不再依赖 Tkinter。需要电脑已有 Python 3 和 Ollama，本地模型已下载并能在 Ollama Chat 回复。

1. 先在原网页 https://zhusichen520.github.io/zhusichen520/studio.html 顶部点“手机＋Ollama”，下载自己的完整 JSON 内容包。它含背景、头像、聊天背景、相册和人物设置。不要清理浏览器数据。
2. 右键 ZIP“全部解压缩”，打开“拾光本机版”。Windows 双击“启动本地版.bat”。黑色窗口会保持打开，浏览器自动进入设置页。
3. 在浏览器选模型、测试 AI，看到实际回复后设置本次作者密码。
4. 在浏览器第 3 步选择之前下载的 JSON，核对作品名、壁纸缩略图和图片数量，保存到本机。
5. 检查内容后发布。手机连同一路由器，用设置页显示的“手机网址”，输入 420802，就能看自己的故事并与已开启 AI 的角色对话。

如果启动仍失败：进入解压后的文件夹，在文件资源管理器上方地址栏输入 cmd 并回车，再输入 start-windows.cmd 并回车。窗口会留下报错。Python 3 was not found 表示没找到 Python 3；Missing launch_web.py 表示文件未全部解压。其他错误看最后几行，或保留 startup-errors.log，不要发送密码。

黑色窗口和 Ollama 必须开着；电脑不能睡眠。手机使用显示的局域网网址，不用 GitHub 演示地址，也不用 127.0.0.1 或 11434。Windows 防火墙需要允许 Python 在专用网络通信，不要关闭整个防火墙，不要暴露 Ollama 到公网。

本机内容在 data/story.db。更新前导出备份，不要删除旧 data 文件夹。原 GitHub 网页与本机版不会自动同步；更换浏览器、电脑或手机也不会自动同步。

本地模型通常没有云 API 按量费用，仍耗费本机算力、电力。手机添加到主屏幕是网页快捷入口，不是原生 APK / App Store 应用。详细教程 https://zhusichen520.github.io/zhusichen520/help-ollama.html 。
